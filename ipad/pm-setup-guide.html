PM AI Scanner

Claude-powered page scanner for unify.performancematters.com — Safari compatible

What it does

When you're on a Performance Matters test or quiz page, tap the bookmark to open a sidebar. It automatically scans all questions and answer choices visible on the page and sends them to Claude, which identifies the correct answers with explanations.

  • Works entirely in Safari — no Chrome extension needed
  • Your API key is stored only in your browser's local storage
  • Tap the bookmark again to close the sidebar

Setup (one time)

1 Get an Anthropic API Key

Go to console.anthropic.com/settings/api-keys and create a key. It starts with sk-ant-. Copy it somewhere safe.

2 Copy the bookmarklet code

Tap the button below, or tap inside the code box and use Select All → Copy:

Safari tip: If the button doesn't copy automatically, tap inside the grey code box above — it will select all. Then tap Copy from the popup menu.
3 Create the bookmark in Safari
  • Open Safari and go to any page (e.g. apple.com)
  • Tap the Share button (box with arrow) → Add Bookmark
  • Name it PM AI Scanner → Save
4 Replace the bookmark URL with the code
  • Tap the book icon (Bookmarks) → Edit
  • Find PM AI Scanner → tap it to edit
  • Tap the URL field, select all, delete it
  • Paste the bookmarklet code you copied in step 2
  • Tap Done
Tip: On Mac Safari, you can edit bookmarks via Bookmarks menu → Edit Bookmarks.

How to use

1 Open a Performance Matters test

Navigate to unify.performancematters.com and open any test, quiz, or assessment page.

2 Tap the bookmark

Open your bookmarks and tap PM AI Scanner. A sidebar appears on the right side of the page.

The tool automatically scans the page and fills the content box. A green status message confirms what was captured.

3 Enter your API key (first time only)

Tap Ask Claude. A prompt will ask for your Anthropic API key. Paste it — it's saved locally so you won't be asked again on this site.

4 Get answers

Claude reads the scanned content and returns answers for each question with brief explanations. Use the Copy Answer button to copy the response.

If some content was missed, tap Re-scan Page or paste content manually into the text box, then tap Ask Claude again.

Troubleshooting

The sidebar opens but the content box is empty
The test page may load questions inside an iframe. Try scrolling to a question first, then tap Re-scan. If still empty, select and copy the question text manually and paste it into the content box.
"Invalid API key — cleared"
Your key was rejected. Tap Ask Claude again and re-enter a valid key from console.anthropic.com.
The sidebar disappears when I navigate to the next question
Tap the bookmark again to re-open it. The Re-scan button will pick up the new question on the current page.
I want to clear my saved API key
Tap the Clear Key button in the top-right of the sidebar header.
The answers seem wrong or incomplete
Add context in the "Your Question" box (e.g. "Focus on question 3") and tap Ask Claude again.

Privacy note

Your API key is stored only in localStorage for unify.performancematters.com. Page content is sent directly to Anthropic's API — no third-party servers are involved. Clearing your browser data will also clear the saved key.
